## 0.1.0-preview.4 - 2026-08-14

- Add the portable validation-package metadata domain.
- Narrow CWL scalar command-input declarations to required, unique prefixes
  and deterministic logical argv materialization.
- Add canonical and read-only legacy validation-packages configuration types,
  strict scalar values, declaration compatibility, and range validation.
- Add SemVer precedence and deterministic package-identity ordering.
- Include Fable sources for .NET, JavaScript, and Python consumers.
- Build installable npm and Python packages alongside the NuGet package.
- Publish one versioned artifact set through independently retriable NuGet,
  npm, and PyPI trusted-publishing jobs.
